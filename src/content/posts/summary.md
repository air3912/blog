# 近半年来的论文阅读总结

这里对近半年来读过的论文做一次分类与回顾。

## 一、基础模型与经典架构

### ResNet：深度残差学习

为了处理退化问题（PS：退化是训练集和测试集都翻车，过拟合是训练集表现还可以）而选择训练残差，即每一层网络都只是进行微调处理，然后针对卷积有三种连接方式，就是通过1\*1卷积核/zero-padding让维度对齐，1\*1卷积通过卷积核数量控制通道数C，然后通过步长控制H/W。zero-padding更简单，想要什么形状的直接加。


### transformer：注意力机制

transformer比较基础但是重要的有三种注意力：
- Self-Attention：多用于对于一个句子的整体理解编码，比如BERT
- Cross-Attention：其中Q是主线投影所得，KV来自想融入的信息，最后再残差连接
- Mask-Attention：将掩码矩阵加到注意力得分上，不想让看到的信息给加到负无穷，然后softmax处理时就mask了，常见的是GPT。

在此基础上还有多头注意力/分组查询注意力等优化显存与计算的版本。还有每一层的残差连接与归一化，以及位置编码：

- 正余弦位置编码：在embedding层之后直接加上位置信息，注意这个编码每一个pos是一个单词，一个单词有d个维度，所以是一个矩阵编码，公式网上可以搜到，这里就不码了（
- RoPE位置编码：在transformer block内QK计算Value权重的前一步，针对每个Q/K向量，每两个维度进行一个旋转处理，最后得到的结果也就是QK相乘后得到的Value权重中的角度信息中会有两个单词彼此间距离的信息。


## 二、视觉语言模态统一

### CLIP：自然语言监督与零样本迁移

CLIP的训练是将文本和频特征对齐，具体做法大概就是每一个batch有N对数据，然后提取特征计算交叉相似度，得到一个N*N相似度矩阵，希望对角线上的数值接近1，其余位置接近0，以此一次性计算这N对数据的损失。大力出奇迹，最后训练出的CLIP在zero-shot上表现优异，few-shot的话，基本没有提升。然后除了关键模型CLIP训练方法外，还有几个实验亮点：

- 提示词工程：对于一些东西不直接丢给文本编码器，而是用模版把标签填进去，对于不同的标签，直接把所有标签都算一遍然后计算平均值也有明显的进步

- 超网络text encoder生成分类头：是实现Zero-shot的基础，就是正常分类是需要从头开始训练分类头的，然后这个就不用，这个可以直接把标签加上提示词输入text encoder，然后将输出拼接得到的就可以作为分类头。


### UFO：用语言接口统一检测与分割
现代模型的检测与分割

- 目标检测：把图像宽高归一化到 [0,1000]的整数，然后对于每一个<box>1,1,2,2</box>这类的，直接作为一个普通token处理。
- 分割：以前都是用大模型加SAM完成这类任务，但是对于每一个大脑，这个SAM都需要单独训练一次，很麻烦，不具性价比，于是有了UFO这种嵌入检索MASK的分割方式，然后很强的想法

1. 首先生成16个MASK向量，维度等于图片token特征维度
2. 然后计算交叉注意力，以每一个 [MASK] Token 作为 Q，去查图片 Token 和文本提示词 Token 的（两组token直接拼接到一起） K,V
3. 16个[MASK]token彼此间做Self-Attention,完成内部分工，然后点乘图片token特征，消除特征维度这一项，然后每个token得到一个完整图像
4. 最后通过1\*1\*16卷积融合，完成分割。



## 三、从图像模型迁移到视频理解

### ViFi-CLIP：用图像模型理解视频

大道至简，前人的做法：3D卷积，帧间注意力，复杂的时序融合模块等等。而作者的做法，抽取T帧按顺序输入做平均池化，然后得到的就作为视频特征，就很....懂吧。虽然也有一些很明显的问题，但是整体表现已经足够好。然后除了这个之外，文中还有些很强的创新：

- Bridge and Prompt 策略：解决few-shot效果很好，对于特定动作的微调，直接用大数据训练VIFI-CLIP后，待其泛化能力足够之后，冻结这些参数，再用few数据微调，就可以识别的很好。Bridge是指打通静态图和动态图之间的差距。Prompt是指轻量微调。


### Open-VCLIP：兼顾视频理解与零样本能力

是对上面VIFI-CLIP的一个升级，解决了其使用视频微调原始CLIP时发生的灾难性遗忘问题。即VIFI-CLIP一定程度上有损原始CLIP强大的泛化能力，基于此，提出了插值权重优化。


- 插值权重优化：就是对于微调后得到的参数，不会直接替换原始CLIP的参数，而是将二者按一定权重比例融合，并且每次前向/反向传播都会经过这一层融合后的权重
- 随机权重平均：把各个 Iteration 的参数存下来做平均，将参数拖到更平坦的区域，泛化能力更强。
- KV拼接时序建模：又是对注意力机制的一种创新，一个很巧妙的时序建模方式，他的Q是本帧的信息，但是KV会融合加上前后两帧的信息，维度变成[3N,D],但是一通计算下来对输出结果的维度不产生影响

这两篇形成了很直接的对照：ViFi-CLIP 说明简单的视频微调和帧特征聚合已经有效，Open-VCLIP 则显式加入时序信息，并通过拉住权重不让其跑太远解决微调后的能力遗忘问题。

## 四、三维场景与语言理解

### 3D-VisTA：预训练三维视觉与文本模型

创建了数据集ScanScribe，首个大规模3D-VL数据集，有着丰富的3D室内场景以及对应的场景描述。

融合了3D-text两个模态，首先是Mask3D分割提取物体点云，归一化送入PointNet++得到物体的特征向量，接着BERT提取文本特征，然后直接拼到一起，进行自注意力计算，得到的特征向量就可以进行下游任务了。

但是如果是预训练，有三个训练方向：
- MLM：融合特征向量预测被mask的文字
- MOM：融合特征向量预测被mask物体的几何特征或类别
- STM：判断场景-text匹配度，CLS向量经过一个二分类头得到0/1；

### LL3DA：让大模型理解三维场景

是具身智能领域一个比较重要的东西，目标是把 3D 物理场景与人类的 3D 交互手势（点/框），全部 Token 化，直接喂给大语言模型主脑，以求完成3D交互任务（ 3D 问答、3D 描述、3D 视觉定位等）

核心架构就是3个编码器，分别得到3D Scene/prompt/text的特征向量，然后拼接，送入transformer计算交叉注意力，生成32个场景token，然后输入主脑，自回归生成回答。需要注意的是这个3D场景编码器，

- prompt encoder（点击）：直接傅立叶位置编码给足信息
- prompt encoder（框选）：一个7维坐标，分别确定中心点坐标以及方框长度以及旋转角度，傅立叶位置编码后一层MLP处理得到空间信息编码，然后这块空间的点素特征也提取一下，最大池化，两个特征向量在相同维度下直接相加，在走一层MLP得到主脑需要的维度
- sence encoder：通过MASK3D分割获得实例特征


### ExCap3D：生成细粒度三维场景描述

细粒化与全局两个captioner，做了一个Excap3D数据集，并用这个数据集做了一个Excap3D model


- 首先提取骨干特征，将原本的3D Mesh体素化，然后输入到3D稀疏卷积神经网络，通过Unet进行稀疏编码，再将得到的结果稠密化，最终得到稠密体素特征，便于输入到transformer进行交叉注意力，最后得到场景中物体的具体信息等。

- 然后冻结Mask3D，将其产出的实例特征向量Q作为Part Captioner的BOS token，后续接上文本作为输入。对于Part captioner，就是接受上面的输入进行自注意力解码，中间插入一个交叉注意力（Q来自文本，然后KV是来自3D体素特征，PS：不会把所有体素全部加进去，而是会进行分割打包，池化）对于object captioner，结构上和上面基本一样，就是KV不只是来自3D体素，而是将part captioner输出前的隐藏状态进行一个投影处理，然后拼接到体素特征的后面，作为交叉注意力的KV信息来源。



## 五、视频中的空间智能评测

### VSI-Bench：评测模型的视觉空间智能

设定了8个任务作为模型考核内容，考察空间视觉智能，然后从CoT分数没有提升可以看出考核的是基础能力，这类能力模型能看到就是看得到，过多思考反而会影响判断。

得出结论现在主流模型无法建立完整的3D空间，他们的空间是破碎的，不过可以通过自行构建认知网格过的一定程度上的进步。


### DSI-Bench：动态空间智能评测基准

相比前者，这篇多了一个观测者移动的考虑，然后设计的每组评分机制，结果更能证实AI的伪智能


## 六、消融实验探索（Ablation Study）

这里就用LSTM相关的这篇论文，这篇文章将LSTM和其8中变体在3个任务上进行了总计5400次实验，这个消融实验

首先消融实验是和控制变量法有一点不一样的，控制变量法一般是改参数之类的，但是Ablation Study一般是做减法，而且他有时候不会只局限于一个部件，有时会进行组合消融。而且消融实验经常会配合着其他的一些操作从而使结果尽可能拟合统计规律。比如：

- 方差分析（ANOVA）：主要用来判断三组或三组以上的平均值之间是否存在显著差异。核心看两点：组间差距和组内波动，通过检查“组内的数据齐不齐”，来验证“组间的平均值差距”到底靠不靠谱。

- 函数式方差分析（fANOVA）：普通的ANOVA只能处理离散的数据，但是这个可以处理连续的数据，相比普通的方差分析操作，这里会先用之前的实验日志训练一个随机森林模型，所以随机搜索参数，随机进行实验，然后得到的数据丢到模型中就可以得到这个东西的贡献率了。

- 每个变体独立调超参数
