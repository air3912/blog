## 一、基础部件

### 1. 三维重建、深度与朝向估计

| Model / 工具 | 描述 |
| --- | --- |
| **Pi3（π³）** | （多目）从多帧 RGB 图像估计三维结构和相机运动（重铸3D空间/解码出3Dtokens） |
| **Depth Anything 3** | （单目） 输入图片预测深度，相机朝向，位置以及参数（生成3D空间结构/也可以为MLLM解码之类的） |
| **Scal3R** | 也是用多视角图像重建三维场景 |
| **Orient Anything** | 估计人、动物或物体的三维朝向 |

### 2. 目标检测、定位与分割

| Model / 工具 | 描述 |
| --- | --- |
| **Grounding DINO** | 根据文本描述在图像中找到目标并输出bbox |
| **YOLO-World** | yolo进化版本，开放词汇检测目标，功能和前者类似，但是各有优劣，可根据实际情况取舍 |
| **SAM2** | 分割图像中的目标，或在视频中持续跟踪目标 mask |
| **Grounded SAM2** | Grounding DINO加SAM 2就是这个 |
| **PixelRefer** | 端到端的Grounded SAM2 |

### 3. 场景描述与视频处理

| Model / 工具 | 描述 |
| --- | --- |
| **PySceneDetect / KTS** | 检测出视频中的分界点（场景变化之类的） |
| **Pix2Cap** | 3D场景caption生成器 |
| **Decord/OpenCV** | 视频数据处理之类的 |

### 4. 训练与评测

| Model / 工具 | 描述 |
| --- | --- |
| **VLMEvalKit** | 评测用的，支持大量benchmark |
| **DeepSpeed** | 显存优化方法，如果单卡显存不够，可考虑 |

## 二、往上封装一层的

### 1. 视频时间定位

| Model / 工具 | 描述 |
| --- | --- |
| **VideoLoom** | 在视频中定位某个动作发生的时间段（根据提示词输出视频中指定动作的时间/mask片段） |

### 2. 空间理解与数据生产

| Model / 工具 | 描述 |
| --- | --- |
| **DSR Suite** | 有一定的空间理解能力，带着问题检索图片与重建的空间找答案，生产数据吧 |
| **MLLM-4D** | 有一定的空间理解能力，可以用来生产数据之类的 |

### 3. 空间关系建图

| Model / 工具 | 描述 |
| --- | --- |
| **UCS-Bench / DirectMe** | 建立空间地图（entity之间的关系） |
